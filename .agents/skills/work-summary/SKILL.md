# Work Summary Skill

Use this skill to document daily work progress.

## Instructions
1. Determine the target application (e.g., BRAIN, AGENT, UI).
2. Gather all tasks completed today.
3. Create a markdown file named according to the target application: `YYYY-MM-DD-[TARGET]-work-summary-[title].md`. For example: `2026-02-21-BRAIN-work-summary-feat-auth.md`.
4. Save the file in the appropriate reports directory (e.g., if BRAIN, save to `docs/reports/brain/`).
5. The document should contain:
   - Date
   - Target area
   - Summary of tasks completed
   - Unresolved issues
